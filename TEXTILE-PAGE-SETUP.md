# DEEDAP Landing Page Setup

The theme includes the supplied animated Textile, Electronics, and Jewelry landing pages as assets.

After uploading the theme:

1. In Shopify Admin, create a page titled **Textiles** with the URL handle `textiles`, then assign the **page.textiles** template.
2. Create a page titled **Electronics** with the URL handle `electronics`, then assign the **page.electronics** template.
3. Create a page titled **Jewelry** with the URL handle `jewelry`, then assign the **page.jewelry** template.
4. In the theme editor, open the Textile and Electronics pages and choose their matching Shopify collections in each DEEDAP section. Textiles has Men, Women, and Kids collection settings. Electronics has Audio, Mobiles, Wearables, Smart Home, Laptops, and Accessories collection settings.
5. If the Shopify Main Menu is configured, add a **Jewelry** item pointing to `/pages/jewelry` so it appears in navigation on the other landing pages too.

The home page Clothing & Textiles, Electronics, and Jewelry entries open their matching landing pages. The Jewelry landing is included in the theme as a section and page template; Shopify requires the Jewelry page itself to be created and assigned that template.
